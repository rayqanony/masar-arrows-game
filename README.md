# لعبة مسار الأسهم (Masar: Unblock Arrows) 🎯

مشروع لعبة ألغاز منطقية بتصميم عصري بسيط (Minimalist Logic Puzzle) مبني باستخدام **Flutter** ومجهز للنشر على متجر **Google Play** مع دعم كامل للغة العربية (RTL) وأول **10 مستويات متدرجة الصعوبة** قابلة للحل 100%.

---

## ✨ مميزات النسخة الحالية (الإصدار التجريبي - أول 10 مستويات)

1. **ميكانيكية أسهم متعددة الرؤوس والالتفافات (Bent Multi-Segment Arrows):**
   - الأسهم ليست مجرد خطوط مستقيمة، بل تتكون من مسارات متداخلة وملتفة (تستقيم تلقائياً أثناء خروجها من الشبكة مثل الثعبان)، مطابقة تماماً للعبة المرجعية.
2. **فحص تصادم ذكي (Ray-casting Collision Detection):**
   - عند الضغط على سهم طريقه مفتوح ينطلق بسلاسة خارج الشاشة.
   - إذا كان طريقه مسدوداً بسهم آخر، يتحرك السهم قليلاً نحو العائق ثم يرتد مع اهتزاز تحذيري ونقصان قلب من القلوب الثلاثة.
3. **الأدوات المساعدة (Power-ups):**
   - **أداة المسطرة (Ruler Guide):** ترسم خطوط مسار متقطعة أمام جميع الأسهم لتوضيح اتجاه خروج كل سهم.
   - **أداة المصباح (Smart Hint):** تفحص الشبكة وتضيء للاعب السهم الصحيح القابل للخروج باللون الذهبي.
4. **واجهات عربية احترافية 100% (RTL):**
   - شاشة اللعب مع شريط التقدم والقلوب الثلاثة ومستوى الصعوبة.
   - شاشة **"اكتمل المستوى!"** بخلفية أشعة زرقاء متحركة (Sunburst Animation) ومعاينة للشكل المكتمل.
   - شاشة **"الإعدادات"** مكتوبة بشكل عربي سليم تماماً (معالجة مشكلة الحروف المعكوسة في اللعبة الأصلية) وتضم التحكم بالصوت، الاهتزاز، المساعدة، حقوق الخصوصية، وإزالة الإعلانات.
   - شاشة اختيار المستويات (من 1 إلى 10).

## 🚀 خطوات رفع المشروع على GitHub وتشغيله

### الطريقة الأولى: الرفع عبر واجهة موقع GitHub مباشرة (بدون أوامر)
1. قم بفك ضغط ملف `masar_arrows_flutter_github.zip` على جهازك.
2. ادخل إلى حسابك على [GitHub](https://github.com) واضغط على **New Repository**.
3. سمِّ المستودع مثلاً `masar-arrows-game` واضغط **Create repository**.
4. اضغط على رابط **uploading an existing file**، واسحب جميع الملفات والمجلدات الموجودة داخل المجلد (`lib`, `pubspec.yaml`, `README.md`, `.github`, `.gitignore`) وارفعها ثم اضغط **Commit changes**.
5. **مفاجأة:** أضفنا لك ملف بناء تلقائي في `.github/workflows/android_build.yml`! بمجرد رفع الملفات على GitHub، سيقوم GitHub Actions تلقائياً ببناء ملف `app-debug.apk` لك في تبويب **Actions** لتتمكن من تحميله وتجربته على هاتفك الأندرويد حتى لو لم يكن لديك فلاتر مثبتاً على جهازك!

### الطريقة الثانية: التشغيل عبر الكمبيوتر (VS Code / Android Studio)
إذا كان لديك Flutter مثبتاً على جهازك، افتح موجه الأوامر (Terminal) داخل مجلد المشروع ونفذ الأوامر التالية:

```bash
# 1. توليد ملفات الأندرويد و iOS القياسية للمشروع
flutter create . --project-name masar_arrows_game --org com.masar.arrows

# 2. تحميل المكتبات
flutter pub get

# 3. تشغيل اللعبة على الهاتف أو المحاكي أو المتصفح
flutter run
```

ولرفعه عبر الأوامر (Git CLI):
```bash
git init
git add .
git commit -m "Initial commit: First 10 levels of Masar Arrows Game"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/masar-arrows-game.git
git push -u origin main
```

## 📂 هيكلة الكود البرمجي

- `lib/main.dart`: الكود الكامل للعبة، ويحتوي على:
  - `ArrowModel` و `Direction`: تمثيل الأسهم متعددة المفاصل واتجاهاتها.
  - `LevelData` و `LevelsRepository`: بيانات أول 10 مستويات مصممة ومفحوصة رياضياً لتكون قابلة للحل خطوة بخطوة.
  - `ArrowBoardPainter`: محرك الرسم المخصص (`CustomPainter`) الذي يرسم الأسهم بحواف دائرية ناعمة، رؤوس الأسهم، خطوط المسطرة، وتأثيرات الإضاءة والتلميح.
  - `SunburstPainter`: رسام الخلفية الشعاعية المتحركة في شاشة الفوز.
  - `SettingsSheet`: شاشة الإعدادات والخصوصية وإزالة الإعلانات باللغة العربية السليمة.
